# PyLab - Virtual Coding Lab

A Next.js and Node.js based virtual lab where students can learn Python through interactive lessons, and admins can manage content. Includes a built-in Python code compiler and progress tracking.

## 🌟 Key Features
- **Role-based access** (Admin & Student)
- **Interactive Python compiler** (runs user code in real-time)
- **Lesson management** (Admins create content, track student progress)
- **Guest mode** (Try the compiler without signing in)
- **PostgreSQL + Prisma** (Type-safe database operations)
- **Hosted on NeonDB** (Serverless PostgreSQL)

## 🛠 Tech Stack
**Frontend:**
- Next.js (App Router)
- React + TypeScript
- Tailwind CSS (Styling)

**Backend:**
- Node.js
- Express.js (API routes)
- Prisma (ORM)
- PostgreSQL (NeonDB)

**Other Tools:**
- JWT (Authentication)
